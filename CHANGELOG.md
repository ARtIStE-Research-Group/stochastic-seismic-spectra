# Changelog

## beta01 — first public release
- Linear and Bouc–Wen (n = 1, equivalent Gaussian linearisation) SDOF analysis.
- Kanai–Tajimi / Clough–Penzien filtered, envelope-modulated Gaussian input; S0 calibrated from PGA.
- Evolutionary Lyapunov covariance integration.
- Covariance of [x, v, a_abs], first-passage peak estimates, mean energy histories.
- Technical manual v2.3-beta included in `docs/` (documents features planned for later releases).
